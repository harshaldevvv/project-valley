# Contributing

Thanks for helping. Bug reports, gameplay feedback and pull requests are all welcome.

- **Bugs:** open an issue with your browser, GPU (press F3 in game to see it), what you did, and what happened. A
  screenshot or short clip helps a lot.
- **Running it:** see [Run it locally](README.md#run-it-locally). `npm test` runs the unit tests.
- **Where things go:** tunable numbers live in `src/content/data/`, player-facing text in `src/content/text/`. Keep
  game state as plain data (see [How it is built](README.md#how-it-is-built)).
- **Assets:** models are generated by the Blender scripts in `tools/blender/`; change the script and rebuild with
  `npm run assets:build` rather than editing GLBs by hand. Any new third-party asset must be CC0 or CC BY and be
  added to [CREDITS.md](CREDITS.md) and `docs/pipeline/asset-credits.md`.
- **Pull requests:** keep each one focused, say how you tested it, and make sure `npm test` and `npm run build` pass.

By contributing you agree that your code and original art are released under the [MIT License](LICENSE).
